# Pharmacovigilance – Task 3

## Causality, Seriousness and Expectedness

### Objective
To assess four sample pharmacovigilance cases using structured causality reasoning, regulatory seriousness criteria, and expectedness assessment against the supplied Velunex product reference.

### Cases Assessed

| Case | Adverse Event | Causality | Seriousness |
|---|---|---|---|
| PV-201 | Dizziness | Possible | Non-serious |
| PV-202 | Appendicitis | Unlikely / Unassessable | Serious – Hospitalization |
| PV-203 | Mild rash | Probable | Non-serious |
| PV-204 | Loss of consciousness | Unassessable / Possible | Serious – Emergency admission |

### Assessment Parameters

Each case was assessed for:

- Valid case elements
- Causality
- Seriousness
- Seriousness criterion
- Severity
- Expectedness
- Missing information
- Follow-up questions
- Causality rationale

### Causality Approach

A structured clinical reasoning approach based on the WHO-UMC causality framework was used. The assessment considers temporal relationship, dechallenge/rechallenge information, alternative causes, concomitant products, and available clinical information.

### Important Note

Causality, seriousness, severity, and expectedness were assessed separately. No definite causal relationship was assigned where the available information was insufficient.

Expectedness should be confirmed against the supplied Velunex reference document.
